# Versioned downloads

These packaged snapshots are used by the Folkin.io skill page. The maintained source remains in `SKILL.md`, `references/`, and `examples/`.

Build a new version with `python3 scripts/package.py`, then copy its ZIP and combined Markdown edition from `dist/` into a new version directory here. Keep previous version directories available so existing links continue to work.

Based on FRAME and Unified Table Language by [Folkin.io](https://folkin.io).
